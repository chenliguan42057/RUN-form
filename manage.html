🔄 同步到仓库

提醒脚本读的是仓库里的 data/plans.json，不是浏览器里的数据。 改动星图后需要同步一次，钉钉提醒才会跟着变。

Token 仅存本机浏览器 localStorage，不发往第三方；填好后会自动同步。 权限：Classic 勾 repo；Fine-grained 给 Contents: read & write + Metadata: read。 安全提示： 定期在 GitHub 轮换 可降低泄露风险；如怀疑 token 已暴露，应立即在 GitHub 撤销并重新生成。

不想在手机上填 40 位 Token？部署 cloudflare/ 里的无令牌代理后， 把它的地址填这里（或留空、由内置地址自动启用）。代理持有 PAT，站点永不接触 Token，手机端零配置即可同步、到点推钉钉。
